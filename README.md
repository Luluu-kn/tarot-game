# Tarot Mini Game | 塔罗自助占卜小游戏
> ✨ For entertainment only, not real fortune-telling.
> ✨ 仅供娱乐，不构成真实占卜与人生指导

## 📖 Project Intro | 项目介绍
This is a self-service tarot web game developed with Python Flask + Frontend HTML/JS.
Users input their question, follow the rules to pick cards, flip the tarot cards one by one, and get AI interpretation.

这是基于 Python Flask + 前端HTML/JS 开发的自助塔罗网页小游戏。用户输入自己想问的问题，按照规则选牌、逐张翻牌，获取AI生成的牌面解读。

## 🛠 Tech Stack | 技术栈
- Backend：Python, Flask
- Frontend：HTML, CSS, JavaScript
- AI：GLM-4.7-Flash API (free version)
- Deploy & Version Control：Git + GitHub

后端：Python、Flask
前端：HTML、CSS、JavaScript
AI接口：智谱 GLM-4.7-Flash（免费额度版）
版本管理：Git + GitHub

## 🎮 Game Flow | 游玩流程
1. User enters the question they want to ask
2. Tip: Interact (like/follow) to get "energy" to unlock divination
3. Select numbers to draw 3 tarot cards
4. Flip cards one by one
5. AI generates gentle interpretation + warm wishes
6. All content is for fun only

1. 用户输入想要咨询的问题
2. 提示互动（点赞/关注）获取能量，开启占卜
3. 选择数字抽取3张塔罗牌
4. 依次翻牌
5. AI生成温和的解读内容 + 美好祝愿
6. 全部内容仅作休闲娱乐
